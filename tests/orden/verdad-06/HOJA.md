## Interfaz de prueba (contrato entre los tests de A y el código de B)
`candado.mjs` lee `tool_name`: con Edit/Write/MultiEdit exige `tool_input.file_path` string (como hoy); con Bash/PowerShell exige `tool_input.command` string; cualquier otra forma (sin `tool_input`, `command` que no es string) → exit 2 «CANDADO ROTO»; `command` vacío → exit 0. El JSON trae `cwd` (Claude Code lo manda en cada PreToolUse): las rutas relativas del comando se resuelven contra `cwd` y, sin él, contra la raíz; `HIGIENE_ROOT=<ruta>` sustituye la raíz sólo para pruebas (como hoy). «Segmento» = lo que parte `&&`, `;`, `||`, `|` y salto de línea (como `segmentos` de tools/_transcript.mjs); «nombra `tests/orden/<id>/`» = el segmento contiene esa ruta (relativa al cwd o absoluta dentro de la raíz) seguida de `/`, de espacio o de fin, también tras `cd`; «lectura reconocida» = el primer token del segmento es uno de la lista de B2 (con `sed` sólo si lleva `-n` y no `-i`; con `git` sólo los subcomandos listados; `node`/`npx` sólo con `--test`). Un veto imprime «CANDADO · …» en stderr con el id de la orden; fuera de `tests/orden/<id>/` el candado no opina sobre shells (exit 0), aunque el comando escriba. Los tests lo invocan con `HIGIENE_ROOT` sobre un repo temporal con una orden con rojo en su historia (`git init` + commit de `tests/orden/vieja-01/HOJA.md`) y otra sin rojo (`tests/orden/nueva-99/`).

C2 corre en el repo real: `git ls-files -s -z` contra `git hash-object --no-filters --stdin-paths` (una llamada, ~600 rutas), modos 100644/100755. C3 y A1 clonan el repo real a un temporal con prefijo «verdad-06-» (`git clone` con la configuración de la máquina, sin `-c`) y corren `npm run prepare` en el clon (lo que haría `npm install`), con `finally`; el enlace a node_modules (sólo A1) es un junction creado con `fs.symlinkSync(…, "junction")` (= `mklink /J`; `NODE_PATH` no sirve para ESM) y se quita antes de borrar el clon.
